# ⚖️ Calculadora de Peso de Lote

Um mini sistema web simples, rápido e otimizado para calcular o peso total de lotes de produtos com base em quantidades e pesos unitários pré-definidos.

Projetado para facilitar a rotina de pesagem e conferência, permitindo navegação rápida via teclado (tecla Enter) e acesso prático pelo celular via QR Code.

---

## 🚀 Funcionalidades

* ⚡ **Cálculo em Tempo Real:** Atualização automática dos subtotais e do peso total do lote conforme a quantidade é digitada.
* ⌨️ **Navegação Ágil com Enter:** Pressionar `Enter` avança automaticamente para o próximo campo de peso sem precisar usar o mouse.
* 🎯 **Auto-Seleção:** Ao focar em um campo, o valor atual fica pré-selecionado para uma digitação mais rápida.
* 🧹 **Botão Limpar:** Zera todos os campos com apenas um clique e retorna o foco para o primeiro item.
* 📱 **Layout Responsivo:** Funciona em computadores, tablets e smartphones.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação da página e formulário.
* **CSS3:** Estilização moderna e responsiva.
* **JavaScript (Vanilla):** Lógica de cálculo dos pesos e manipulação de eventos de teclado.
